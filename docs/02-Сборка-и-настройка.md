# Сборка `.erf` и настройка отчёта

Бинарный `.erf` собирается платформой 1С — в среде, где готовились исходники,
платформы нет, поэтому ниже два пути: автоматический и ручной.
**Ручной путь гарантированно рабочий**, автоматический — быстрее, но его результат
нужно один раз проверить загрузкой.

## Путь 1. Сборка одной командой (Конфигуратор, пакетный режим)

```bat
"C:\Program Files\1cv8\8.3.xx.xxxx\bin\1cv8.exe" DESIGNER ^
  /F "C:\bases\erp_copy2" /N Администратор /P пароль ^
  /LoadExternalDataProcessorOrReportFromFiles ^
  "<путь к репозиторию>\src\ГантПоЗаказамНаПроизводство.xml" ^
  "C:\erf\ГантПоЗаказамНаПроизводство.erf" ^
  /Out "C:\erf\build.log"
```

Обратная операция (выгрузить уже собранный `.erf` обратно в исходники — удобно
для последующих правок через git):

```bat
... /DumpExternalDataProcessorOrReportToFiles "<каталог src>" "C:\erf\ГантПоЗаказамНаПроизводство.erf"
```

Если загрузка ругается на структуру XML — используйте путь 2, он занимает ~10 минут.

## Путь 2. Ручная сборка в Конфигураторе

1. **Файл → Новый → Внешний отчёт**, имя `ГантПоЗаказамНаПроизводство`,
   синоним «Гант по заказам на производство».
2. **Основная схема компоновки данных** → добавить.
3. Набор данных **«Запрос»**, имя `ЗаказыНаПроизводство`.
   В текст запроса вставить `src/Запросы/ЗапросОтчета.txt` целиком.
   Нажать «Заполнить поля» — все поля появятся автоматически.
4. Вкладка **«Вычисляемые поля»**:

   | Путь | Выражение | Заголовок |
   |---|---|---|
   | `ДлительностьДней` | `РазностьДат(ДатаНачала, ДатаОкончания, "ДЕНЬ")` | Длительность, дней |

5. Вкладка **«Ресурсы»** — обязательна для диаграммы Ганта
   (значения точек диаграммы берутся только из ресурсов):

   | Поле | Выражение |
   |---|---|
   | `ДатаНачала` | `Минимум(ДатаНачала)` |
   | `ДатаОкончания` | `Максимум(ДатаОкончания)` |
   | `ДлительностьДней` | `Максимум(ДлительностьДней)` |
   | `КоличествоДнейПлан` | `Максимум(КоличествоДнейПлан)` |
   | `КоличествоЭтапов` | `Максимум(КоличествоЭтапов)` |
   | `ЗавершеноЭтапов` | `Максимум(ЗавершеноЭтапов)` |

6. Вкладка **«Параметры»**:

   | Имя | Тип | Значение по умолчанию | Примечание |
   |---|---|---|---|
   | `СвойствоКоличествоДней` | `ПланВидовХарактеристикСсылка.ДополнительныеРеквизитыИСведения` | — | доступен пользователю |
   | `НачалоПериода` | Дата (состав — дата) | пустая | пустая = без ограничения |
   | `КонецПериода` | Дата (состав — дата) | пустая | пустая = без ограничения |
   | `Статусы` | `ПеречислениеСсылка.СтатусыЗаказовНаПроизводство2_5` | список: `Формируется`, `КПроизводству` | флажок «Список значений» |

7. Вкладка **«Настройки»**, структура отчёта — три элемента подряд:

   **Диаграмма 1 — «Формируется»**
   - Добавить → *Диаграмма*.
   - **Точки**: `Заказ` (сортировка по `ДатаНачала` возр.).
   - **Серии**: `ВидИнтервала` (сортировка по `ПорядокВида` возр.).
   - **Значение**: `ДатаНачала`, затем `ДатаОкончания` — строго в этом порядке
     (первый ресурс = начало интервала, второй = конец).
   - **Отбор**: `Статус = Формируется`, `ЭтоФакт = Ложь`.
   - **Параметры вывода**: `Тип диаграммы = Диаграмма Ганта`,
     заголовок «Заказы на производство в статусе «Формируется» (план)»,
     легенда — снизу.

   **Диаграмма 2 — «К производству»** — то же самое, но:
   - **Отбор**: только `Статус = КПроизводству` (обе серии, План и Факт).
   - Заголовок «Заказы на производство в статусе «К производству» (план / факт)».

   **Таблица-расшифровка** (необязательно, но удобно):
   - Строки: `Статус` → `Заказ`; Колонки: `ВидИнтервала`;
   - Показатели: `ДатаНачала`, `ДатаОкончания`, `ДлительностьДней`,
     `КоличествоДнейПлан`, `КоличествоЭтапов`, `ЗавершеноЭтапов`.

8. **Модуль объекта** — вставить `src/ГантПоЗаказамНаПроизводство/Ext/ObjectModule.bsl`
   (автоподстановка доп. реквизита «Количество дней», если пользователь его не выбрал).
9. Сохранить как `ГантПоЗаказамНаПроизводство.erf`.
10. Подключить: **НСИ и администрирование → Печатные формы, отчёты и обработки →
    Дополнительные отчёты и обработки** (вид — «Отчёт», разместить в разделе
    «Производство»).

## Проверка после подключения

1. Открыть отчёт, выбрать доп. реквизит «Количество дней» (или убедиться,
   что он подставился сам), задать период, сформировать.
2. Ожидаемая картина:
   - верхняя диаграмма — только заказы «Формируется», одна полоса «План» на заказ;
   - нижняя — заказы «К производству», по две полосы: «План» и «Факт»;
   - в таблице у «К производству» заполнены `КоличествоЭтапов`/`ЗавершеноЭтапов`.
3. Заказ, у которого «Количество дней» не заполнен, покажет план по датам самого
   ЗНП — это признак незаполненного доп. реквизита в основании, а не ошибка отчёта.

## Правка запроса

Текст запроса — единственный источник правды: `src/Запросы/ЗапросОтчета.txt`.
После его изменения пересобрать схему:

```bash
python3 tools/gen_schema.py
```

Схема `src/.../Ext/Template.xml` перегенерируется с новым текстом запроса.
