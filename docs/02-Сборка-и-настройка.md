# Сборка `.erf` и настройка отчёта

Бинарный `.erf` собирается платформой 1С — в среде, где готовились исходники,
платформы нет, поэтому ниже два пути: автоматический и ручной.
**Ручной путь гарантированно рабочий**, автоматический — быстрее, но его результат
нужно один раз проверить загрузкой.

## Путь 1. Сборка одной командой (Конфигуратор, пакетный режим)

```bat
"C:\Program Files\1cv8\8.3.xx.xxxx\bin\1cv8.exe" DESIGNER ^
  /F "C:\bases\erp_copy2" /N Администратор /P пароль ^
  /LoadExternalDataProcessorOrReportFromFiles ^
  "<путь к репозиторию>\src\ГантПоЗаказамНаПроизводство.xml" ^
  "C:\erf\ГантПоЗаказамНаПроизводство.erf" ^
  /Out "C:\erf\build.log"
```

Обратная операция (выгрузить собранный `.erf` в исходники — удобно для правок в git):

```bat
... /DumpExternalDataProcessorOrReportToFiles "<каталог src>" "C:\erf\ГантПоЗаказамНаПроизводство.erf"
```

Если загрузка ругается на структуру XML — используйте путь 2, он занимает ~15 минут.

## Путь 2. Ручная сборка в Конфигураторе

1. **Файл → Новый → Внешний отчёт**, имя `ГантПоЗаказамНаПроизводство`,
   синоним «Гант по заказам на производство».
2. **Основная схема компоновки данных** → добавить.
3. Набор данных **«Запрос»**, имя `ЗаказыНаПроизводство`.
   Вставить текст из `src/Запросы/ЗапросОтчета.txt`, нажать «Заполнить поля».
4. **Вычисляемые поля**:

   | Путь | Выражение | Заголовок |
   |---|---|---|
   | `ДлительностьДней` | `РазностьДат(ДатаНачала, ДатаОкончания, "ДЕНЬ")` | Длительность, дней |

5. **Ресурсы** — обязательны: значения точек диаграммы Ганта берутся только из ресурсов.

   | Поле | Выражение |
   |---|---|
   | `ДатаНачала` | `Минимум(ДатаНачала)` |
   | `ДатаОкончания` | `Максимум(ДатаОкончания)` |
   | `НачатьНеРанее` | `Минимум(НачатьНеРанее)` |
   | `ЖелаемаяДатаВыпуска` | `Максимум(ЖелаемаяДатаВыпуска)` |
   | `СрокИзготовленияДней` | `Максимум(СрокИзготовленияДней)` |
   | `НачатФакт` | `Минимум(НачатФакт)` |
   | `ЗавершенФакт` | `Максимум(ЗавершенФакт)` |
   | `ДлительностьДней` | `Максимум(ДлительностьДней)` |

6. **Параметры**:

   | Имя | Тип | По умолчанию |
   |---|---|---|
   | `СвойствоСрокИзготовления` | `ПланВидовХарактеристикСсылка.ДополнительныеРеквизитыИСведения` | — (доступен пользователю) |
   | `НачалоПериода` | Дата (состав — дата) | пустая = без ограничения |
   | `КонецПериода` | Дата (состав — дата) | пустая = без ограничения |
   | `Статусы` | `ПеречислениеСсылка.СтатусыЗаказовНаПроизводство2_5`, флажок «Список значений» | `Формируется`, `КПроизводству` |

7. **Настройки** — структура из четырёх элементов, по образцу `ПРИМЕР.xlsx`:

   **7.1. Диаграмма «ПРОГНОЗ» (статус «Формируется»)**
   - Добавить → *Диаграмма*, параметр вывода **Тип диаграммы = Диаграмма Ганта**.
   - **Точки** — две вложенные группировки: `ДокументОснование` → `Заказ`
     (сортировка внутренней по `ДатаНачала` возр.).
   - **Серии**: `ВидИнтервала`, сортировка по `ПорядокВида`,
     отбор серии `ЭтоФакт = Ложь` (в этом статусе этапов ещё нет).
   - **Значение**: `ДатаНачала`, затем `ДатаОкончания` — строго в этом порядке
     (первый ресурс = начало интервала, второй = окончание).
   - **Отбор диаграммы**: `Статус = Формируется`.
   - Заголовок: «ПРОГНОЗ. Статус заказа «Формируется»».

   **7.2. Таблица-расшифровка к «ПРОГНОЗ»**
   - Строки: `ДокументОснование` → `Заказ`; отбор `Статус = Формируется`.
   - Показатели (порядок колонок как в образце): `НачатьНеРанее`, `НачатФакт`,
     `ЗавершенФакт`, `ЖелаемаяДатаВыпуска`, `СрокИзготовленияДней`,
     `ДатаНачала`, `ДатаОкончания`, `ДлительностьДней`.

   **7.3. Диаграмма «ПЛАН» (статус «К производству»)**
   - То же, но **точки — три уровня**: `ДокументОснование` → `Заказ` → `Этап`,
     отбор диаграммы `Статус = КПроизводству`, отбор по `ЭтоФакт` **не ставить**
     (нужны обе серии: «План» на уровне заказа и «Факт» на уровне этапов).
   - Заголовок: «ПЛАН. Статус заказа «К производству»».

   **7.4. Таблица-расшифровка к «ПЛАН»** — строки `ДокументОснование` → `Заказ` → `Этап`,
   отбор `Статус = КПроизводству`, показатели те же.

8. **Модуль объекта** — вставить `src/ГантПоЗаказамНаПроизводство/Ext/ObjectModule.bsl`.
9. Сохранить как `ГантПоЗаказамНаПроизводство.erf`.
10. Подключить: **НСИ и администрирование → Печатные формы, отчёты и обработки →
    Дополнительные отчёты и обработки**, вид «Отчёт», раздел «Производство».

### Цвета серий (как в образце: план — жёлтый, факт — красный)

В параметрах вывода диаграммы задать палитру вручную либо в оформлении назначить
цвет серии: `ВидИнтервала = "План"` — жёлтый, `ВидИнтервала = "Факт"` — красный.

## Проверка после подключения

1. Открыть отчёт, убедиться, что доп. реквизит «Срок изготовления, к дней»
   подставился (или выбрать вручную), задать период, сформировать.
2. Ожидаемая картина:
   - верхний блок — только заказы «Формируется», под каждым основанием
     по одной плановой полосе на заказ;
   - нижний блок — заказы «К производству»: плановая полоса на уровне заказа
     и отдельная фактическая полоса на каждый этап;
   - в таблицах — колонки «Начать не ранее», «Начат», «Завершен»,
     «Желаемая дата выпуска», «Срок изготовления, к дней».
3. Контроль на данных образца: ЗНП со сроком 15 дней и «Начать не ранее» 10.06
   должен дать полосу 10.06–25.06, этап с фактом 24.06–25.06 — свою полосу внутри заказа.

## Правка запроса

Текст запроса — единственный источник правды: `src/Запросы/ЗапросОтчета.txt`.
После изменения пересобрать схему:

```bash
python3 tools/gen_schema.py
```
