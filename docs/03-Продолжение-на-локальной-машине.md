# Продолжение работы на машине с Конфигуратором

Веб-сессия Claude Code работает в изолированном облачном контейнере: платформы 1С
и базы `erp_copy2` там нет, поэтому собрать и проверить `.erf` можно только локально.
Ниже — как перенести работу на машину, где стоит Конфигуратор.

## 1. Поставить Claude Code локально

Вариант А — десктоп-приложение Claude Code (Windows/Mac), скачивается со страницы
документации https://code.claude.com/docs

Вариант Б — CLI (нужен Node.js 18+):

```powershell
npm install -g @anthropic-ai/claude-code
```

Запуск в папке проекта:

```powershell
claude
```

## 2. Забрать эту ветку

```powershell
git clone https://github.com/it2026citr-byte/https-code.claude.com-docs-en-web-quickstart.git
cd https-code.claude.com-docs-en-web-quickstart
git checkout claude/gantt-production-orders-yt387e
```

## 3. Стартовый запрос для локальной сессии

Скопировать целиком в первое сообщение:

> В репозитории лежит внешний отчёт СКД «Гант по заказам на производство» для
> 1С:ERP 2.5 (см. README.md и docs/01-Анализ-ТЗ.md). На этой машине есть платформа
> 1С и база erp_copy2. Нужно:
> 1) прогнать tools/ДиагностикаМетаданных.bsl в erp_copy2 и сверить реальные имена
>    реквизитов с таблицей допущений в docs/01-Анализ-ТЗ.md (в запросе они помечены
>    [ПРОВЕРИТЬ]): «Начать не ранее» и «Желаемая дата выпуска» в
>    Документ.ЗаказНаПроизводство2_5, связь ЗНП с заказом клиента/давальца,
>    фактические и плановые даты в Документ.ЭтапПроизводства2_5;
> 2) поправить src/Запросы/ЗапросОтчета.txt под фактические имена и пересобрать
>    схему: python3 tools/gen_schema.py;
> 3) собрать .erf: build\build_erf.bat "<путь или строка подключения к erp_copy2>"
>    <пользователь> [пароль]; если загрузка XML не пройдёт — собрать вручную по
>    docs/02-Сборка-и-настройка.md;
> 4) открыть отчёт в базе, сформировать и сравнить вывод с образцом:
>    блок ПРОГНОЗ (статус «Формируется», основание → заказ) и блок ПЛАН
>    (статус «К производству», основание → заказ → этап, план на заказе,
>    факт отдельной полосой на каждый этап).

## 4. Что локальная сессия может, а веб — нет

| | веб-сессия | локальная сессия |
|---|---|---|
| Правка запроса и схемы, документация | да | да |
| Чтение метаданных `erp_copy2` | нет | да |
| Сборка `.erf` Конфигуратором | нет | да |
| Запуск отчёта и сверка с образцом | нет | да |

## 5. Полезные команды пакетного режима

Сборка `.erf` из исходников:

```powershell
& "C:\Program Files\1cv8\8.3.xx.xxxx\bin\1cv8.exe" DESIGNER /F "C:\bases\erp_copy2" `
  /N Администратор /P пароль `
  /LoadExternalDataProcessorOrReportFromFiles "src\ГантПоЗаказамНаПроизводство.xml" `
  "build\ГантПоЗаказамНаПроизводство.erf" /Out "build\build.log"
```

Обратная выгрузка `.erf` в исходники (после правок в Конфигураторе — чтобы вернуть
изменения в git):

```powershell
& "C:\Program Files\1cv8\8.3.xx.xxxx\bin\1cv8.exe" DESIGNER /F "C:\bases\erp_copy2" `
  /N Администратор /P пароль `
  /DumpExternalDataProcessorOrReportToFiles "src" "build\ГантПоЗаказамНаПроизводство.erf"
```
