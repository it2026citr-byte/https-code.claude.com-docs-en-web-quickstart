# GitHub Pages

`index.html` — копия `ИИ-и-боты/scanner/mexc-scanner.html`, отсюда её раздаёт GitHub Pages.

Чтобы включить: Settings → Pages → Source: «Deploy from a branch» →
ветка `claude/tradingview-integration-91pkkb`, папка `/docs` → Save.

Адрес после включения:
https://it2026citr-byte.github.io/https-code.claude.com-docs-en-web-quickstart/

Обновить сайт после правок сканера:
    cp ИИ-и-боты/scanner/mexc-scanner.html docs/index.html && git commit -am "обновление сканера" && git push
