# Гант по заказам на производство (1С:ERP 2.5)

Внешний отчёт на СКД: план/факт производства двумя диаграммами Ганта —
отдельно по заказам на производство в статусе «Формируется» и
отдельно в статусе «К производству».

- **План** — дата начала заказа на производство + «Количество дней»
  (доп. реквизит документа-основания: заказ клиента / заказ давальца).
- **Факт** — по этапам производства заказа: фактические даты этапов,
  а где факта ещё нет — плановые даты этапа.

## Состав

```
src/Запросы/ЗапросОтчета.txt        текст запроса (источник правды)
src/ГантПоЗаказамНаПроизводство.xml исходники внешнего отчёта (выгрузка в XML)
src/ГантПоЗаказамНаПроизводство/
    Ext/ObjectModule.bsl            модуль объекта отчёта
    Templates/…/Ext/Template.xml    схема компоновки данных (запрос + 2 диаграммы Ганта)
tools/gen_schema.py                 пересборка схемы СКД из текста запроса
tools/ДиагностикаМетаданных.bsl     выгрузка фактических имён реквизитов из базы
docs/01-Анализ-ТЗ.md                решения по ТЗ, допущения, открытые вопросы
docs/02-Сборка-и-настройка.md       сборка .erf и настройка диаграмм
```

## Быстрый старт

1. Прогнать `tools/ДиагностикаМетаданных.bsl` в `erp_copy2` и сверить имена
   реквизитов с таблицей допущений в `docs/01-Анализ-ТЗ.md`.
2. Собрать `.erf` — `docs/02-Сборка-и-настройка.md` (пакетная команда или
   ручная сборка в Конфигураторе).
3. Подключить как дополнительный отчёт в разделе «Производство».

## Важно

Исходники подготовлены без доступа к конфигурации `erp_copy2` и без платформы 1С,
поэтому имена реквизитов ЗНП и этапов — по типовой ERP 2.5 и помечены в запросе
как `[ПРОВЕРИТЬ]`. Логика расчёта план/факт от этих имён не зависит.
