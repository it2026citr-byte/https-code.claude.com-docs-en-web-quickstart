# Чек-лист тестирования базы 1С:ERP `erp_copy2` + автотесты Vanessa Automation

Комплект материалов для построения регрессионного тестирования базы `erp_copy2`
(сервер `erpdevs`) с прицелом на автоматизацию через Vanessa Automation (VA).

| Часть | Состояние | Комментарий |
|---|---|---|
| Каркас чек-листа по типовой ERP 2.5 | ✅ готово | `docs/02-test-checklist.md` — 230 проверок по 13 подсистемам |
| Стратегия автотестирования VA | ✅ готово | `docs/03-vanessa-automation.md` |

| **Привязка к реальным объектам `erp_copy2`** | ⛔ **не сделано** | нет сетевого доступа к базе — см. ниже |

## Чего здесь нет и почему

Материалы построены на **типовой конфигурации «1С:ERP Управление предприятием 2»
(редакция 2.5)**. Реальный состав объектов вашей базы — какие справочники
заполнены, какие документы реально используются, какие есть доработки,
дополнительные реквизиты, изменённые формы и обмены — **не учтён**, потому что
подключиться к `erpdevs\erp_copy2` из среды, где я запущен, невозможно
(изолированный облачный контейнер, маршрута в вашу локальную сеть нет).

Из-за этого сейчас нельзя гарантировать:

- что все перечисленные объекты у вас включены (часть функциональных опций ERP может быть выключена — тогда проверки лишние);
- что перечень полон (доработки и расширения не покрыты);
- что связи между объектами именно такие (могли быть изменены).

**Как это закрывается:** раздел [«Сбор структуры базы»](docs/01-collect-db-structure.md)
содержит готовые скрипты. Запустите их на базе, приложите выгрузки — и чек-лист
дотачивается под фактическое содержимое `erp_copy2` за один проход.

## Порядок работы

1. **Собрать структуру.** Выполнить `tools/DbStatistics.bsl` и
   `tools/ObjectLinksMap.bsl` на `erp_copy2` → получить `db_statistics.csv` и
   `object_links.csv`. Подробности: [`docs/01-collect-db-structure.md`](docs/01-collect-db-structure.md).
2. **Отсечь неиспользуемое.** По `db_statistics.csv` вычеркнуть из чек-листа
   объекты с нулевым количеством записей — это сразу срежет 30–50 % проверок.
3. **Добавить доработки.** Всё, чего нет в типовой (префиксы расширений,
   свои объекты), — дописать в чек-лист по образцу.
4. **Приоритизировать.** По [`docs/04-coverage-matrix.md`](docs/04-coverage-matrix.md)
   разметить проверки на P0/P1/P2 и «авто/ручной».
5. **Автоматизировать.** Начать с P0-сценариев по образцам из `tests/features/`.
   Стратегия и обвязка CI: [`docs/03-vanessa-automation.md`](docs/03-vanessa-automation.md).

## Допущения

- Конфигурация — 1С:ERP УП 2, ред. 2.5 (для 2.4 применимо ~85 % чек-листа,
  расхождения в производстве 2.1/2.2 и в этапах);
- платформа 8.3.20+, клиент-серверный вариант;
- `erp_copy2` — копия рабочей базы, пригодная для разрушающих тестов;
- тестирование регрессионное, не приёмочное по новому внедрению.

Если хоть одно допущение неверно — скажите, скорректирую.
