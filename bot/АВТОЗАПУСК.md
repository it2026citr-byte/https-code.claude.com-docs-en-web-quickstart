# Автозапуск бота после перезагрузки

Аддона **Termux:Boot** в Google Play нет (проверено — 404), поэтому
поднимаем связкой: **MacroDroid** открывает Termux при загрузке,
а Termux сам запускает бота через сторожа.

Сторож — `termux-run.sh` — делает три вещи: не даёт запуститься второй
копии, держит замок пробуждения и поднимает бота, если тот упал.

---

## 1. Обновить код

```
cd ~/repo && git pull
```

## 2. Остановить бота, запущенного вручную

Перейди во вкладку, где он бежит, и нажми **CTRL** в нижнем ряду
клавиш Termux, затем **C**. Появится приглашение `~/repo/bot $`.

Это обязательно: иначе получится две копии, а Telegram пускает к очереди
только одну — вторая упадёт с ошибкой 409.

## 3. Прописать автозапуск в Termux

Одной командой:

```
printf '\n# автозапуск бота\n(nohup sh ~/repo/bot/termux-run.sh >/dev/null 2>&1 &)\n' >> ~/.bashrc
```

Теперь при каждом открытии Termux бот поднимается сам. Если он уже
работает, сторож это увидит и второй копии не создаст.

Проверить прямо сейчас, не перезагружаясь:

```
sh ~/repo/bot/termux-run.sh
sh ~/repo/bot/termux-run.sh status
```

Вторая команда должна ответить `работает, PID …`.

## 4. Настроить MacroDroid

1. Открыть MacroDroid → **Макросы** → **+**
2. **Триггеры** → **+** → *События устройства* → **Загрузка устройства завершена**
3. **Действия** → **+** → *Приложения* → **Запуск приложения** → выбрать **Termux**
4. Ограничения — пропустить
5. Назвать «Автозапуск бота» → сохранить

### Разрешения, без которых не сработает

Android запрещает открывать приложения из фона, поэтому MacroDroid нужно:

* **Поверх других окон** — Настройки → Приложения → MacroDroid → Поверх других окон → разрешить;
* **Автозапуск** самого MacroDroid — Настройки → Приложения → MacroDroid → Автозапуск (на Xiaomi, Huawei, Oppo этот пункт обязателен);
* **Батарея → «Без ограничений»** — и для MacroDroid, и для Termux.

## 5. Проверить

Перезагрузить планшет. Через минуту-две написать боту `/status` —
должен ответить.

---

## Управление сторожем

```
sh ~/repo/bot/termux-run.sh          запустить
sh ~/repo/bot/termux-run.sh status   узнать, работает ли
sh ~/repo/bot/termux-run.sh stop     остановить
```

## Где смотреть, что было

```
tail -30 ~/repo/bot/storage/bot.log
```

Лог обрезается автоматически на двух мегабайтах, диск не забьёт.

Строка `--- бот остановился, поднимаю через 10 секунд ---` означает,
что бот падал и был поднят. Если таких строк много подряд — смотри,
что написано выше каждой: там причина.

## Обновление бота потом

```
sh ~/repo/bot/termux-run.sh stop
cd ~/repo && git pull
sh ~/repo/bot/termux-run.sh
```

База сделок лежит в `bot/storage/` и в репозиторий не входит —
обновление кода её не тронет.
