# Запуск прямо на телефоне (Android, Termux)

Сразу честно: **распаковать архив и «открыть» его нельзя** — это не
приложение. Нужен Node.js, а на Android его нет. Termux — это терминал
Linux внутри Android, он и даёт Node.js.

Работает. Но у способа есть цена — она в конце, прочти её до того,
как решишь оставить бота на телефоне навсегда.

---

## Шаг 1. Поставить Termux

**Не из Google Play** — там версия старая и сломанная.

Бери с **F-Droid** (`f-droid.org`, найти Termux) либо с GitHub:
`github.com/termux/termux-app/releases` → в последнем релизе файл
`termux-app_...universal.apk`.

Android спросит разрешение ставить из неизвестных источников — разрешить.

## Шаг 2. Поставить Node.js

Открыть Termux и набрать по очереди (`Enter` после каждой строки):

```
pkg update -y && pkg upgrade -y
pkg install nodejs unzip -y
node -v
```

Последняя команда должна показать `v22.5.0` или выше. Если ниже —
`pkg upgrade nodejs`.

## Шаг 3. Дать доступ к файлам телефона

```
termux-setup-storage
```

Android спросит разрешение — дать. После этого папка «Загрузки»
доступна как `~/storage/downloads`.

## Шаг 4. Распаковать и запустить

Архив должен лежать в «Загрузках» телефона. Дальше:

```
cd ~
unzip -o "$(find ~/storage -name 'signal-bot*.zip' | head -1)"
cd bot
npm start
```

Команда сама находит архив, куда бы его ни положил Telegram —
в «Загрузки» или в `Download/Telegram`. Если ничего не нашла,
посмотри глазами:

```
find ~/storage -name '*.zip'
```

Признак успеха — те же три строки, что и на компьютере:

```
бот @Alfbi_bot на связи
TradingView: 1674 пар, после фильтров 67
опрос Telegram запущен
```

Теперь в Telegram найти **@Alfbi_bot** и нажать «Начать».

## Шаг 5. Чтобы Android не убил бота

Это главное. Без этих трёх вещей бот проживёт минут двадцать после того,
как погаснет экран.

**1. Замок пробуждения.** В Termux новая вкладка (свайп от левого края →
«New session») и там:

```
termux-wake-lock
```

**2. Снять ограничение батареи.** Настройки Android → Приложения → Termux →
Батарея → **«Без ограничений»** (на разных прошивках: «Не оптимизировать»,
«Разрешить работу в фоне»). На Xiaomi, Huawei, Samsung и Oppo это
обязательно — их «умная» экономия убивает фоновые процессы жёстче всего.

**3. Не смахивать Termux из недавних.** Смахнул — бот остановился.
Пусть висит в уведомлениях.

**Автозапуск после перезагрузки** (по желанию): поставить addon
**Termux:Boot** оттуда же, откуда Termux, один раз открыть его, затем:

```
mkdir -p ~/.termux/boot
cat > ~/.termux/boot/bot.sh <<'END'
#!/data/data/com.termux/files/usr/bin/sh
termux-wake-lock
cd ~/bot && npm start
END
chmod +x ~/.termux/boot/bot.sh
```

## Цена этого способа

**Трафик.** В режиме скана бот тянет полный срез рынка каждые 15 минут —
около 1 МБ за раз, примерно **100 МБ в сутки**. На мобильном тарифе это
заметно. Держи на Wi-Fi, либо переводи в `/focus` — там трафик падает
в сотни раз (следит только за твоими сделками).

**Батарея и нагрев.** Круглосуточная работа с постоянной сетью греет
телефон и сажает батарею. Держи на зарядке.

**Надёжность.** Android вправе убить любой фоновый процесс, когда захочет —
и делает это чаще всего ночью, при слабом сигнале и низком заряде. То есть
ровно тогда, когда рынок ходит. Бот при старте честно скажет, сколько его
не было, но пропущенный выход этим не вернёшь.

## Чем это отличается от компьютера

| | Телефон (Termux) | Компьютер | VPS ~5 $/мес |
|---|---|---|---|
| Всегда с собой | да | нет | неважно |
| Переживает ночь | как повезёт | если не выключать | да |
| Трафик | твой мобильный | домашний | входит в тариф |
| Настройка | 5 шагов выше | одна команда | копирование папки |

**Мой совет:** отладить на компьютере, а когда пойдут живые сделки —
перенести на VPS. Телефон хорош как временный вариант и как страховка
на случай, когда компьютера рядом нет.

Код везде одинаковый. Переезд — это копирование папки `bot`.

## Если не заработало

**`pkg: command not found`** — поставил Termux из Google Play. Снести,
поставить с F-Droid.

**`node: not found` после установки** — закрыть Termux полностью
и открыть заново.

**`unzip: cannot find or open`** — файла нет по этому пути.
Проверь `ls ~/storage/downloads/`.

**`Permission denied` при `termux-setup-storage`** — разрешение не дано.
Настройки → Приложения → Termux → Разрешения → Файлы.

**Бот замолкает через 10–20 минут** — не сделан шаг 5. Все три пункта.
