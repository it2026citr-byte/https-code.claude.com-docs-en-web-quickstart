# MEXC Signal Scanner

Одностраничный сайт: сам ходит в TradingView, сканирует все пары биржи MEXC
к USDT и выдаёт торговые сигналы с готовыми уровнями. Сервер не нужен.

## Как запустить

**Локально:** откройте `mexc-scanner.html` двойным щелчком. Всё.

**На телефоне или с доступом откуда угодно:** положите файл на любой статический
хостинг — GitHub Pages, Netlify, Cloudflare Pages, Vercel. Файл самодостаточный,
внешних зависимостей нет.

## Что внутри

* **Данные** — скринер TradingView (`scanner.tradingview.com/crypto/scan`),
  фильтр по бирже MEXC. Около 1700 пар к USDT с индикаторами на 15м / 1ч / 4ч / 1д.
* **Сигнал** — на каждом таймфрейме три голоса: CCI, гистограмма MACD, ансамбль
  скользящих средних. Счёт от −3 до +3. Консенсус — взвешенное среднее,
  1ч и 4ч весят вдвое больше 15м и суток.
* **Уровни** — стоп = множитель × ATR(1ч) (по умолчанию 1.5 — величина,
  восстановленная из разбора 415 сигналов Crypto Signals Golden).
  Цели по их формуле: T(n) = вход ± 0,5·n × расстояние до стопа.
* **Размер позиции** — от вашего риска в процентах депозита.
* **Уведомления** — браузерные, при появлении нового сигнала.
  Настройки и список уже показанных сигналов хранятся в браузере.

## Технические детали

Два момента, без которых страница бы не работала:

1. **Content-Type: text/plain** вместо `application/json`. У TradingView в
   `access-control-allow-headers` только `Referer` и `Accept`, поэтому JSON-заголовок
   вызвал бы предзапрос CORS и получил отказ. `text/plain` входит в белый список
   и предзапрос не вызывает — при этом сервер прекрасно разбирает тело как JSON.

2. **Оборот в долларах считается на странице.** Скринер сортирует по объёму
   в монетах, из-за чего верх списка занимают микро-токены с триллионами единиц,
   а BTC и ETH проваливаются вниз. Поэтому запрашиваются все пары, оборот
   пересчитывается в доллары и уже по нему берётся топ-N.

MEXC напрямую из браузера недоступен: их API не отдаёт заголовок
`access-control-allow-origin`, поэтому запрос заблокирует любой браузер.
Данные MEXC берутся через TradingView, который CORS поддерживает полностью.

Не является финансовой рекомендацией.
