# Хроника работы: что делали и почему

Восстановлено по переписке. Полный лог чата выгрузить не удалось — Claude не имеет
доступа к транскриптам ни этого, ни других чатов (инструмента для чтения переписки
не существует, а системный каталог заблокирован политикой). Поэтому здесь —
содержательная выжимка: все решения, находки и тупики в том порядке, в котором они
случились.

---

## 1. Подключение к TradingView

**Задача:** «подключить тебя к трейдинг вью».

Официального коннектора TradingView в каталоге Claude нет (проверено:
в каталоге есть Alpha Vantage, FMP, Crypto.com — TradingView отсутствует).
Поэтому написан собственный MCP-сервер на TypeScript поверх публичных эндпоинтов,
тех же, что использует сайт tradingview.com. API-ключ не нужен.

Файлы: `src/index.ts`, `src/client.ts`, `src/technicals.ts`.

Четыре инструмента: поиск тикеров, котировки до 50 символов за раз,
теханализ по таймфреймам от 1м до 1М, скринер рынков. Все проверены вживую
(например, по запросу «sberbank» находится `RUS:SBER`).

## 2. Сборка стратегии из индикаторов

Пользователь присылал индикаторы по одному; каждый добавлялся слоем:

1. **CCI** (справка TradingView) — фильтр импульса
2. **UT Bot Alerts** (QuantNomad) — генератор входов по ATR-трейлинг-стопу.
   Исходный код прислан текстом, порт на Pine v6 сверен построчно.
3. **Squeeze Momentum** (LazyBear) — фильтр волатильности.
   Важно: в опубликованном коде LazyBear есть опечатка — в расчёте полос
   Боллинджера стоит `multKC` вместо `mult`, из-за чего настройка «BB MultFactor»
   не работает. Автор её исправил в обновлении; в нашей сборке используется
   исправленный вариант.
4. **Smart Money Concepts** (LuxAlgo) — фильтр структуры рынка.
   Полный скрипт LuxAlgo огромен; взято его ядро — leg-детектор свингов
   и сломы структуры BOS/CHoCH на двух уровнях (Internal 5 / Swing 50),
   плюс зоны Premium/Discount. Ордер-блоки, FVG и EQH/EQL не переносились:
   у самого LuxAlgo это визуальные слои, на сигналы они не влияют.

Результат: `strategies/universal-strategy.pine`.

**Тупик, который стоит помнить:** код пользовательских скриптов со страниц
`tradingview.com/script/...` вытащить программно нельзя — он подгружается через
`pine-facade.tradingview.com`, требующий авторизации (ответ:
`The user requesting information on the script is not allowed to do so`).
Проще попросить пользователя прислать код текстом.

## 3. Сканер рынка

Сначала сделан пакетный сканер на Node (`signals/generate.mjs`), который собирает
статический `dashboard.html` по топ-30 парам Binance и публикуется артефактом.
Настроено автообновление раз в 15 минут через самопробуждение сессии.

**Что пошло не так:** фоновое переиздание артефакта заблокировал классификатор
разрешений — в автономном пробуждении без пользователя он не пропустил ни
публикацию, ни постановку следующего таймера. Цепочка обновлений оборвалась.
Вывод на будущее: круглосуточные автообновления внутри сессии Claude ненадёжны,
для этого нужен внешний планировщик.

## 4. Разбор Crypto Signals Golden

Ключевая часть работы. Подробности — в `03-РАЗБОР-GOLDEN.md`.

**Как собирались данные.** Пользователь прислал семь видеозаписей экрана
приложения. Конвейер распознавания:

1. `ffmpeg` (ставился через `pip install imageio-ffmpeg`, потому что `apt` в
   окружении не работал) режет видео на кадры: `fps=3`, фильтр `mpdecimate`
   отбрасывает дубликаты, `crop` убирает шапку и панель навигации.
2. Кадры склеиваются по три в горизонтальные тайлы — так за одно чтение
   изображения распознаётся втрое больше карточек.
3. Каждый тайл читается и переносится в CSV.

Итого 415 уникальных сигналов. Дедупликация по ключу
`(время закрытия, тип, пара, цена входа)` — цену входа пришлось добавить в ключ,
потому что у них бывает по несколько разных сигналов на одну пару в одну минуту
(ORDIUSDT 8 августа 3:10 — три разных входа: 3.538 / 3.425 / 3.362).

**Гипотеза пользователя, которая подтвердилась:** «по каждой валюте используется
только одна стратегия». Проверено на группах повторных сигналов — во всех
7 из 7 направление совпадает. Ни одного случая встречных позиций.

**Что не подтвердилось.** Простая формула «стоп = k × ATR» не работает:
нормировка на ATR снижает разброс лишь с 0,48 до 0,39 (для настоящего правила
ожидалось бы ~0,10). Структурный стоп за свинговым экстремумом даёт совпадение
26–29% против ~12% случайных — вдвое лучше случайности, но тоже не правило.
Скорее всего, гибрид.

**Попытка восстановить время входа.** Для каждого сигнала искали по 15-минутным
свечам MEXC последнее касание цены входа перед закрытием. Сработало для 91%
сигналов и дало важный факт — медиану удержания 2,5 часа. Но точность оказалась
недостаточной: пересчёт ATR на восстановленный момент входа статистику не улучшил
(среднее изменение −0,011).

## 5. Стратегия Golden Reverse

`strategies/golden-reverse-strategy.pine` — синтез: их геометрия выходов
(проверенная) + наш движок входов (потому что их правило входа не разгадано)
+ нормальный риск-менеджмент вместо их 30% на сделку.

При написании поймано три реальные ошибки Pine, которые стоит помнить:

* Pine **не допускает** перечисление присваиваний через запятую
  (`a := 1, b := 2`) — только по строке на присваивание.
* Функции объявляются **только на верхнем уровне**, внутри `if` нельзя.
* `qty_percent` в `strategy.exit` считается от **текущей** позиции, а не от
  исходной, поэтому лесенка 20/20/20/20/20 «съезжает». Плюс уже сработавшую
  цель нельзя переоткрывать — нужны защёлки.

## 6. Живой сканер MEXC

`scanner/mexc-scanner.html` — одностраничный сайт без сервера.

**Почему сайт, а не артефакт.** Артефакт живёт в песочнице со строгой политикой
безопасности, которая блокирует любые запросы наружу. Живых данных внутри
артефакта быть не может в принципе — проверено по документации возможностей.
Обычный HTML-файл такого ограничения не имеет.

**Три находки, без которых бы не заработало** — см. `04-ТЕХНИЧЕСКИЕ-НАХОДКИ.md`.

**Как тестировался.** Chromium через Playwright: страница загружалась с
подменённым `window.fetch`, отдающим реальный сохранённый ответ TradingView.
Так проверены разбор данных, подсчёт голосов, сортировка, поиск, расчёт уровней
и мобильная вёрстка на размерах iPhone 13 (390 px) и Pixel 7 (412 px).
Сам сетевой запрос из браузера проверить не удалось — в песочнице у Chromium
нет доступа в сеть (даже example.com недоступен), поэтому сетевой слой
проверялся отдельно через curl.

## 7. Что осталось нерешённым

* **Правило входа Golden** — главный незакрытый вопрос. Нужны времена открытия.
* **Сканер у пользователя не заработал** — на момент написания причина неизвестна,
  диагностика не проводилась. Возможные направления: региональная блокировка
  tradingview.com, особенности открытия локального файла на телефоне,
  обрезанная ссылка.
* **GitHub Pages не включены** — API включения заблокирован прокси в окружении
  Claude, нужны три клика вручную в настройках репозитория.
* **Google Drive** — коннектор отвалился в середине работы, загрузка файлов
  в папку стала невозможна.
