## 1. Бот — `../bot/`

Единственная часть раздела, которая лежит **вне** его. Она осталась на месте
намеренно: на планшете бот запускается по пути `~/repo/bot/`, а его база
(`bot/storage/`) в гит не попадает и переезд оторвал бы её от кода. Трогать
не нужно — работает как работал.

Что читать:

| Файл | О чём |
|---|---|
| [`../bot/ИНСТРУКЦИЯ.md`](../bot/ИНСТРУКЦИЯ.md) | Как пользоваться: команды, кнопки, настройки, что делать если молчит |
| [`../bot/СТРАТЕГИИ.md`](../bot/СТРАТЕГИИ.md) | Алгоритмы всех четырёх стратегий и сканера отстающих; как добавить свою |
| [`../bot/ЗАПУСК.md`](../bot/ЗАПУСК.md) | Устройство кода, файл за файлом |
| [`../bot/ЗАПУСК-НА-ТЕЛЕФОНЕ.md`](../bot/ЗАПУСК-НА-ТЕЛЕФОНЕ.md) | Установка в Termux с нуля |
| [`../bot/АВТОЗАПУСК.md`](../bot/АВТОЗАПУСК.md) | Сторож, который поднимает бота после перезагрузки |

Коротко про устройство: Node 22, нулевые зависимости (`node:sqlite` встроен),
23 файла. Стратегии лежат отдельными файлами в `bot/strategies/` и
подхватываются реестром сами — новая стратегия это новый файл, ядро править
не нужно.

Четыре стратегии: **Golden-Reverse** (геометрия выходов, восстановленная из
415 чужих сигналов), **SMC-Confluence**, **MA-Cross-CCI**, **Funding-Impulse**
(двухэтапная, по ставке финансирования). Плюс **сканер отстающих** — ищет не
сигнал в монете, а пару «лидер скакнул → похожая по форме графика ещё стоит».

## 3. Стратегии TradingView — `strategies/`

**`golden-reverse-strategy.pine`** — главный результат разбора. Лесенка целей
T(n) = вход ± 0,5·n × расстояние до стопа, адаптивный стоп (ATR ×1.5 /
структурный / гибрид), безубыток после второй цели. Риск 1% вместо чужих 30%.
График 1 час.

**`universal-strategy.pine`** — ранняя сборка: UT Bot + CCI + Squeeze Momentum
(LazyBear) + Smart Money Concepts.

Вставляются в Pine Editor на TradingView как есть.

## 4. Сканер — `scanner/`

**`mexc-scanner.html`** — одностраничный сайт: сам ходит в TradingView,
сканирует пары MEXC к USDT, выдаёт сигналы с уровнями. Ни сервера, ни сборки —
открывается двойным щелчком, свёрстан под телефон. Разбор устройства —
[`scanner/README.md`](scanner/README.md).

Копия для GitHub Pages лежит отдельно, в `../docs/index.html` (Pages раздаёт
только `docs/` в корне, поэтому её сюда не переносили). Обновляется так:

```
cp ИИ-и-боты/scanner/mexc-scanner.html docs/index.html
```

## Что не разгадано

**Правило входа Golden.** Геометрия выходов восстановлена полностью, вход —
нет. Нужны времена *открытия* сигналов; в приложении видно только время
закрытия. Лучший источник — история push-уведомлений на телефоне.
