## 1. Стратегии для TradingView (папка strategies/)

**golden-reverse-strategy.pine** — главный результат.
Выходы восстановлены из 415 разобранных сигналов Golden:
  • лесенка целей T(n) = вход ± 0.5·n × расстояние до стопа (подтверждено на 100%)
  • адаптивный стоп: ATR ×1.5 / структурный за свингом / гибрид
  • перевод в безубыток после 2-й цели, опциональный трейлинг
Входы — наши (UT Bot + CCI + Squeeze Momentum + SMC), потому что правило
входа Golden восстановить не удалось.
Риск: 1% на сделку вместо их 30%.
Рекомендуемый график: 1 час.

**universal-strategy.pine** — более ранняя сборка из четырёх индикаторов:
UT Bot (QuantNomad) + CCI + Squeeze Momentum (LazyBear) + Smart Money Concepts.

## 3. Анализ

**atr_cluster.py** — кластеризация: качает свечи MEXC, считает ATR(14) на
15м/1ч/4ч/1д в момент каждого сигнала, нормирует расстояние до стопа.
**atr_clusters.json** — результат.

Выводы:
  • Стратегия ОДНА, не несколько. Внутри пары нет дискретных пресетов
    (SL% — непрерывное распределение), между парами множитель k = стоп/ATR(1ч)
    тоже непрерывен от 0.81 до 2.68.
  • Направление на паре всегда одно: 7 из 7 групп повторных сигналов.
  • Горизонт внутридневной: медиана удержания 2.5 часа.
  • Стоп ≈ 1.5 × ATR(1ч) ≈ 0.35 × ATR(день), часто около свингового
    экстремума 15м/1ч (вдвое чаще случайного).
  • Матожидание +0.93R на сделку при удержании до цели; всего +0.10R,
    если закрывать всё на первой цели.
  • Их риск 30% депозита на сделку при 27% стопов — главная опасность.

Не разгадано: точное правило ВХОДА. Нужны времена ОТКРЫТИЯ сигналов
(история push-уведомлений), в приложении видно только время закрытия.
