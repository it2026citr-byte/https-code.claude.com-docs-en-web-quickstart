# Если сканер не работает

Страница целиком выполняется в браузере и ходит только в один адрес —
`scanner.tradingview.com`. Поэтому причин отказа немного.

## Что показывает страница

При ошибке под шапкой появляется красная плашка с текстом
«Не удалось получить данные» и самой ошибкой. Точка статуса становится красной.
**Сообщите текст этой плашки** — по нему причина определяется однозначно.

## Причина 1: доступ к TradingView закрыт

Самое вероятное. Проверка: откройте в том же браузере
`https://scanner.tradingview.com/crypto/scan` — если страница не грузится или
висит, значит домен недоступен из вашей сети (провайдер, регион, корпоративный
фильтр, DNS).

Симптом в плашке: `Failed to fetch` или `NetworkError`.

Решение: VPN, либо смена DNS, либо мобильный интернет вместо Wi-Fi.

## Причина 2: локальный файл на телефоне

Мобильные браузеры часто отказываются нормально открывать `.html` с диска:
Chrome на Android может показать исходник или предложить скачать файл,
многие файловые менеджеры открывают HTML во встроенном просмотрщике
без выполнения JavaScript.

Решение: не открывать файл локально, а пользоваться ссылкой:

```
https://raw.githack.com/it2026citr-byte/https-code.claude.com-docs-en-web-quickstart/claude/tradingview-integration-91pkkb/docs/index.html
```

Ссылка длинная — при копировании из мессенджера легко обрезается.
Проверьте, что она заканчивается на `docs/index.html`.

## Причина 3: ссылка githack исчерпала лимит

Домен `raw.githack.com` бесплатный и без гарантий. Если он отдаёт ошибку,
включите GitHub Pages — это надёжнее:

Settings репозитория → Pages → Source «Deploy from a branch» →
ветка `claude/tradingview-integration-91pkkb` → папка **`/docs`** (не `/root`!) → Save.
Через 1–2 минуты заработает
`https://it2026citr-byte.github.io/https-code.claude.com-docs-en-web-quickstart/`

Либо перетащите `scanner/mexc-scanner.html` на `app.netlify.com/drop` —
постоянный адрес за десять секунд без регистрации.

## Причина 4: пусто, но ошибки нет

Если плашки нет, статус зелёный, а таблица пустая — сработали фильтры.
Снизьте «Порог сигнала» до 0 и увеличьте «Топ по обороту».

## Быстрая проверка API вручную

Из терминала на компьютере:

```bash
curl -s -X POST https://scanner.tradingview.com/crypto/scan \
  -H 'Content-Type: text/plain' \
  --data '{"filter":[{"left":"exchange","operation":"equal","right":"MEXC"}],
           "columns":["name","close"],"range":[0,3]}'
```

Ожидаемый ответ — JSON с парами MEXC. Если приходит ошибка или ничего,
проблема в доступе к TradingView, а не в странице.
